# TIDEFORM 90 天家具营销方案

## 1. 定位

TIDEFORM 以“铝型材框架 + 海洋级板材”的完整家具进入市场，而不是销售裸型材。产品价值来自清晰结构、可见材料组合、模块化尺寸语言和标准/定制双路径。

原型定位语：

> Furniture built from frame and panel.

标准产品负责降低决策成本，定制项目负责承接尺寸、颜色、组合、项目数量和特殊空间需求。板材基材、性能、户外适用、承重和耐久性未核实前不进入广告主张。

## 2. 首发受众

| 受众 | 痛点 | 内容重点 | 首要 Offer |
| --- | --- | --- | --- |
| 设计意识家庭用户 | 普通家具笨重、尺寸难适配 | 房间场景、比例、颜色、标准尺寸 | 标准款浏览/购买 |
| 小户型与工作室 | 深度、墙宽、储物和工作面受限 | 测量方法、窄体/低矮家具、开放结构 | Measuring guide + RFQ |
| 室内设计师 | 需要材料样本、颜色与项目尺寸 | 材料细节、色板、HTML 规格、项目流程 | 材料/色板请求 |
| 酒店、小商业与联合办公 | 重复件、项目数量、交付协调 | 系列一致性、数量、配置、交付输入 | Project RFQ |

首 90 天优先家庭/工作室的 Storage、Console、Shelving 三类，同时小规模验证设计师项目线索。不同时铺开所有房间、户外和大型合同家具叙事。

## 3. 首发 Offer 架构

1. **标准家具：** 4-5 个可购物款，明确尺寸、颜色、原型价格与上线依赖。
2. **定制一件：** 以现有款为起点，修改尺寸、颜色或储物布局。
3. **空间测量指南：** 低门槛内容资产，连接浏览与 RFQ。
4. **材料/色板请求：** 在真实样板、成本、邮寄范围和跟进流程建立后上线。
5. **项目家具：** 多件、设计师、酒店与商业场景进入项目 RFQ。

不要用折扣掩盖尚未验证的产品/履约。第一轮激励优先选择色板抵扣、设计咨询抵扣或样板运费抵扣，前提是财务和履约已批准。

## 4. 渠道优先级

### 第一优先：自有站 + 搜索

- 家具类型 PDP、Living Collection、Materials、Custom Projects、Measuring Guide。
- 先解决信息完整、视觉一致、标准/定制路径和证据边界。
- 品牌词尚未建立时，非品牌搜索聚焦具体家具和空间任务。

### 第一优先：Pinterest 与 Instagram

- Pinterest 承接房间、颜色、尺寸与长期收藏意图。
- Instagram 用完成家具、材料细节、房间变化和系列一致性建立品牌识别。
- 每条内容链接到具体 PDP、Collection、Materials 或 Measuring，不全部回首页。

### 第二优先：设计师与小型项目外联

- 建立 30-50 位目标室内设计师、造型师、小型酒店/工作室名单。
- 外联内容包含 1 张完整家具图、1 张结构细节图、尺寸/颜色范围和项目入口。
- 不群发空泛品牌介绍；每次基于项目风格或具体空间说明相关性。

### 第二优先：Email

- 浏览/色板/项目来源分段。
- 欢迎流：品牌材料语言 -> 首发系列 -> 测量指南 -> 定制入口。
- 项目线索邮件与普通零售促销分开，保留负责人和状态。

### 第三优先：付费搜索与 Shopping

- 只有正式 SKU、价格、库存、配送、退货、图片权利和 Checkout 全部通过后启动 Shopping。
- 搜索广告先投高意图家具词和定制词，否定 raw extrusion、machine guarding、industrial profile、DIY frame 等错位意图。
- 每个广告组进入对应类型/定制页，不用首页承接所有词。

## 5. 内容支柱

| 支柱 | 示例 | 商业作用 |
| --- | --- | --- |
| 完整家具 | Sideboard、Console、Shelving 的正面/三分之二视角 | 建立品类识别 |
| 房间比例 | 长墙、玄关、媒体墙、工作室场景 | 连接空间任务 |
| Frame + Panel | 铝框转角、板面、门/搁板接口 | 解释差异化 |
| 尺寸与测量 | 墙宽、深度、操作间隙、送货路径 | 提高 RFQ 质量、降低误配 |
| 颜色系统 | Ocean Green、Graphite、Cool Gray、Burgundy、Arctic White | 支持选择与收藏 |
| 标准到定制 | 同一款的标准尺寸和定制输入 | 解释双交易路径 |
| 护理与组装 | 只发布与确认材料/硬件绑定的说明 | 降低售后风险 |

## 6. 视觉资产计划

每个首发 SKU 最低需要：

- 白/冷灰背景主图，4:3。
- 正面、三分之二、侧面或开门/搁板视角。
- 房间场景图。
- 铝框与板面细节图。
- 标准颜色样片或经校准的色板图。
- 代码原生尺寸表；尺寸文字不只放在图中。

AI 场景图负责构图、空间和氛围；真实产品、供应商批准的源图或技术资料负责交易事实。发布前人工核对门数、搁板、框架、脚垫、颜色、比例和附件。保留原始文件、prompt、模型/版本、日期、审核人及 IPTC 生成式来源元数据。

## 7. 90 天执行

### 第 1-2 周：事实与样本冻结

- 确认正式品牌候选、主体、域名和公开联系渠道。
- 选定 4-6 个首发家具款和标准/定制路径。
- 收集实际板材名称、基材、厚度、饰面、边缘、颜色、护理和限制。
- 收集铝框饰面、连接、脚垫、包装、组装、承重和版本资料。
- 建立 claim ledger、SKU 表和素材 QA 清单。

闸门：未形成稳定 SKU 和材料证据时，保持 prototype/noindex，不启动付费流量。

### 第 3-4 周：商品与内容资产

- 完成每款主图、场景图、细节图和尺寸 HTML。
- 完成 Home、Products、PDP、Living、Materials、Custom Projects、Measuring。
- 建立材料/色板申请的成本和跟进规则。
- 连接 Shopify 测试商品、Cart、Checkout 与真实市场配置。

闸门：产品、价格、库存、政策和图片未核对时，不上线 Merchant feed。

### 第 5-6 周：软启动

- 邀请 10-20 名目标用户完成移动端浏览、尺寸理解、颜色选择和 RFQ。
- 每周发布 3-5 条视觉内容：2 个完成家具、1 个材料细节、1 个测量/空间、1 个标准到定制。
- 向首批 15-20 位设计师发送个性化介绍。
- 记录搜索词、站内搜索、PDP 到 Cart、PDP 到 RFQ、RFQ 完整率和问题类型。

闸门：修复错误流量、常见信息缺口、RFQ 低质量原因和移动端问题后再放大。

### 第 7-9 周：验证渠道

- Pinterest 建立 Furniture Type、Small Space、Materials、Color 四组 Board。
- Instagram 用同一系列的空间/细节/尺寸内容建立连续性。
- 对 2-3 个高意图搜索组做小额测试，设置错位工业词否定关键词。
- 对设计师线索测试材料包或项目咨询入口。

闸门：以合格购买/合格 RFQ 成本和毛利空间决定加预算，不以点击率单独决策。

### 第 10-12 周：扩大或收敛

- 保留带来合格购买/RFQ 的家具类型、空间内容和渠道。
- 合并低信息量页面，停止吸引 raw material/DIY industrial 意图的内容。
- 建立 PDP、颜色、尺寸、场景和 RFQ 的第二轮实验。
- 形成下一季系列决策：扩 Storage、Shelving 或 Work Table 中表现最好的方向。

## 8. 转化路径

### 标准家具

`Content/Search -> Collection/PDP -> Size + Finish -> Cart -> Shopify Checkout -> Order`

### 定制家具

`Content/Search/Designer outreach -> PDP/Materials/Measuring -> Custom Projects -> RFQ -> Qualified review -> Quote -> Controlled order`

### 色板/材料

`Materials/Designer content -> Sample request -> Qualified contact -> Sample delivery -> PDP/RFQ -> Order/Project`

色板路径仅在真实样板、库存、邮寄区域、成本、隐私和跟进 SLA 准备好后上线。

## 9. 实验优先级

1. PDP CTA：`Customize this piece` 与 `Request custom dimensions`。
2. 房间场景主图与纯商品主图的 PDP 进入率。
3. 尺寸信息靠近价格与单独规格区的理解度。
4. 颜色色板顺序与默认颜色。
5. Measuring Guide 在 PDP 与 Custom Projects 的链接位置。
6. 设计师入口是否需要单独表单，在项目线索量达到门槛后再决定。

每次实验只改变一个主变量，预先写明假设、主指标、护栏指标、最小样本/时间和停止条件。低流量不强行宣称统计显著。

## 10. 依赖与责任

| 依赖 | 负责角色 | 未满足时 |
| --- | --- | --- |
| 品牌、主体、域名、政策 | Business / Legal | 保持 prototype/noindex |
| 板材和铝框规格、色板、承重、护理 | Product / Supplier | 不发布性能和使用主张 |
| SKU、价格、库存、变体 | Commerce | 不输出 Offer/Feed |
| 包装、组装、配送、退货 | Operations | 不承诺交付和安装 |
| 图片结构与颜色 QA | Product / Creative | 不上传 PDP/广告 |
| RFQ 负责人、通知、状态、报价 | Sales / Operations | 原型只收集不对外承诺 SLA |
| GA4、GSC、同意与 CRM | Analytics / Legal | 只做本地事件验证 |

## 11. 决策指标

- 标准产品：PDP view -> finish/size selection -> add_to_cart -> checkout -> purchase。
- 定制项目：PDP/guide -> RFQ start -> valid submit -> qualified -> quote -> won。
- 内容辅助：首次内容入口后 30 天内的 purchase/qualified RFQ，使用聚合、非个人化报告。
- 质量护栏：退货、退款、破损、错色/错尺寸、无效 RFQ、客服问题、页面性能和 consent 状态。

定义和事件契约以 [Measurement plan](./measurement-plan.md) 为准。
